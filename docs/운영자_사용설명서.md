## 1. 시작하기 (가입·로그인)

### 권한 등급
| 레벨 | 명칭 | 설명 |
|---|---|---|
| 0 | ADMIN | 운영자 기능 전부 + 시스템 관리 메뉴 |
| 1 | 운영자 | 근무표·인사·연차·오버타임 등 관리 기능 전부 |
| 2 | 직원 | 조회·신청 위주 (별도 문서 참고) |

> 가입 시 권한은 **이름·생년월일**로 직원 인증 후 자동 부여됩니다. (운영자로 등록된 사람은 운영자로 들어옵니다.)

### 가입 방법
1. 로그인 화면에서 **직원 가입** 탭 선택
2. **성명 + 생년월일** 입력 → **본인 확인**
3. 확인되면 **이메일 + 비밀번호(6자 이상)** 설정 → **계정 생성**
4. **로그인** 탭으로 돌아가 로그인

## 2. 화면 구성

왼쪽 **사이드바**에서 메뉴를 이동합니다. (모바일에서는 좌측 상단 **☰ 메뉴** 버튼)

운영자 메뉴: **대시보드 · 직원 명단 · 인사관리 · 근무표 · 연차 관리 · 오버타임 확인 · 입퇴사 관리 · 사용 설명서**
(ADMIN 레벨은 **시스템 관리** 메뉴가 추가로 표시됩니다.)

---

## 3. 대시보드

- **오늘 근무 중인 직원만** 팀별로 표시됩니다. (휴무·연차자는 근무표에서 제외)
- 상단 요약 카드: 총 재직 인원, 오늘 근무·반차 인원, 휴무, 연차, 마케팅/기타
- 휴무·연차 카드에 마우스를 올리면 **해당 명단**이 펼쳐집니다.
- 당일 **생일자**가 있으면 상단에 배너로 표시됩니다.

---

## 4. 직원 명단

- 재직 중인 전체 직원을 **팀별**로 한눈에 봅니다. (이름·소속·직급·입사일·연락처)
- 상단 검색창에서 이름·직급·부서로 검색할 수 있습니다.
- *상세 편집·등록은 **인사관리** 메뉴에서 합니다.*

---

## 5. 인사관리

직원 정보를 **등록·수정·삭제**하는 관리자 전용 화면입니다.

### 직원 추가
1. 우측 상단 **+ 직원 추가**
2. 사번·성명·소속·직급·입사일 등 입력 (사번·성명·소속·직급·입사일 필수)
3. **등록**

### 직원 수정 / 삭제
- 각 행 우측 **수정** → 인라인으로 값 변경 후 **저장**
- **삭제** → 확인 후 삭제 (관련 데이터도 함께 정리됩니다 — 주의)

### 민감정보 보기 (급여·주민번호)
- 기본적으로 **급여**는 `●●●●●`, **주민번호**는 앞 7자리만 표시됩니다.
- 우측 상단 **민감정보 보기** 체크박스를 켜면 급여·주민번호 전체가 표시됩니다.

### 표시 항목
사번 · 이름 · 소속 · 직급 · 전화번호 · 이메일 · 생년월일 · 주민번호 · 입사일 · 퇴사일 · 급여(계약) · 이전 직장 · 비고 · 상태

## 6. 근무표 (핵심)

### 6-1. 월 이동
- 상단 **◀ / ▶** 버튼 또는 **연/월 선택**으로 달을 이동합니다.

### 6-2. 근무 입력
셀(칸)을 클릭하면 상태 선택 팝업이 뜹니다.

| 키 | 상태 |
|---|---|
| `D` | 근무 |
| `S` | 추가근무 |
| `H` | 반차 |
| `Y` | 연차 |
| `O` | 휴무(OFF) |
| `Backspace`/`Delete` | 비우기 |

- **키보드 단축키**: 셀 선택 후 위 키를 누르면 바로 입력됩니다. **방향키**로 셀 이동.
- **빠른 입력 팁**: D·S·H·Y·O 키 + 방향키로 빠르게 채울 수 있습니다.

### 6-3. 복사 · 붙여넣기 (엑셀처럼)
1. 셀 클릭 → 팝업에서 **복사** 버튼
2. 다른 셀들을 **클릭**하면 연속으로 붙여넣기됩니다.
3. **Esc** 로 붙여넣기 모드 종료.

### 6-4. 연차 반영 (신청 연차 불러오기)
- 상단 **연차 반영** 버튼을 누르면, 직원들이 **신청한 연차/반차**를 해당 날짜에 `Y`/`H`로 채워줍니다.
- **기존 근무는 지우지 않습니다.** 신청 연차가 있는 날짜 칸만 채웁니다.
  - 그 칸에 이미 다른 근무(D 등)가 있었다면 **연차로 덮어씁니다.**
- 반영은 참고용이며, **확정 전까지 자유롭게 수정**할 수 있습니다.

> 연차 신청은 승인/거절 절차 없이 **관리자가 참고하는 용도**입니다. 실제 연차 일수는 **확정된 근무표**의 Y/H로 집계됩니다.

### 6-5. 오프(희망 휴무) 겹침 경고
- **오프 설정** 버튼에서 파트별 최대 희망 오프 인원을 정합니다.
- 같은 파트에서 연차(Y)가 설정값을 초과하면 날짜 헤더에 **❗** 가 뜨고, 마우스를 올리면 명단이 보입니다.
- **총괄실장은 실장 파트로 묶여서** 판정됩니다.

### 6-6. 확정 (직원 공개)
- 작성 중에는 **임시저장(미공개)** 상태입니다.
- **확정하기 →** 를 누르면 직원에게 **직원 공개 중**으로 표시됩니다.
- 확정 후에도 셀을 수정할 수 있으며, **확정된 근무표의 수정 내역은 기록**됩니다(아래 변경 기록).
- **공개 취소**로 다시 미공개로 되돌릴 수 있습니다.

### 6-7. 변경 기록
상단 **변경 기록** 버튼 → 두 가지 탭:
- **교환 기록**: 직원 간 근무 교환(맞바꿈) 내역 + 요청 처리 내역(수락/거절/취소)
- **관리자 수정**: 확정된 근무표에서 관리자가 직접 바꾼 셀 내역 (변경 전→후, 시각)

> 운영자·직원 모두 변경 기록을 조회할 수 있습니다.

### 6-8. 내보내기 / 인쇄
- **엑셀(전체)** / **엑셀(직원용)** — 스타일 포함 .xlsx
- **이미지** — 화면 근무표를 PNG로 (마케팅·미분류 제외, 근무 파트만)
- **인쇄(전체)** / **인쇄(직원용)**

## 7. 연차 관리

세 가지 탭으로 구성됩니다.

- **연차 현황**: 직원별 총 연차 / 사용 / 잔여 / 사용률. 직원을 선택하면 월별 상세.
- **연차 내역**: 신청 내역 전체 목록 (등록일·기간·일수·구분).
- **달력**: 월별 연차/반차자를 달력으로.

### 연차 등록 (직원 대신 기입)
- **+ 연차 등록** → 직원·구분(연차/반차)·기간·일수 입력
- 반차는 오전/오후 선택, 종료일은 시작일과 동일
- **일수**를 바꾸면 **종료일이 자동 계산**됩니다 (종료일을 바꾸면 일수 자동).

### 총 연차 일수 수정
- 현황 표에서 각 직원의 **총 연차 `✎`** 를 눌러 직접 수정.

### ⚠️ 집계 기준
- 사용/잔여는 **확정된 근무표**의 연차(Y)·반차(H)만 집계합니다.
- 아직 확정 전인 달의 Y/H는 잔여에 반영되지 않습니다.

---

## 8. 오버타임 확인

- 상단 **◀ / ▶** 로 **이전·다음 달** 기록을 조회합니다.
- 오버타임은 **매월 1일 0시에 리셋**됩니다 (이월되지 않음).
- 파트별로 직원 카드가 표시되며, 카드를 누르면 **전체 적립·사용 내역**을 봅니다.
- **+ 오버타임 추가** 로 직원의 적립/사용을 분 단위로 등록.

---

## 9. 입퇴사 관리

- **입사**: 등록 시 직원이 자동 생성됩니다. (이름·소속·직급)
- **퇴사**: 직원 선택 → 퇴사일 입력 → 상태가 '퇴사'로 변경됩니다.
- 입퇴사 이력이 날짜순으로 기록됩니다.

## 10. 근무 상태 표기

| 표기 | 의미 |
|---|---|
| **D** | 정상 근무 |

## 11. 자주 묻는 질문

**Q. 직원이 연차를 신청했는데 근무표에 자동으로 안 들어가요.**
A. 정상입니다. 신청은 참고용이며, 관리자가 **연차 반영** 버튼으로 불러오거나 직접 입력해야 근무표에 반영됩니다.

**Q. 연차 잔여가 제가 입력한 것과 달라요.**
A. 잔여는 **확정된 달**의 근무표 Y/H만 집계합니다. 해당 달을 **확정**하면 반영됩니다.

**Q. 근무표를 확정한 뒤 수정해도 되나요?**
A. 됩니다. 단, 확정된 근무표의 수정은 **변경 기록 → 관리자 수정** 탭에 남습니다.

**Q. 이미지 내보내기에 마케팅·미분류가 안 보여요.**
A. 의도된 동작입니다. 근무표 화면·이미지는 근무 파트만 표시합니다.

**Q. 직원 간 근무 교환은 어떻게 되나요?**
A. 직원이 확정된 근무표에서 같은 파트원에게 교환을 **요청**하고, 상대가 **수락**하면 맞바꿈됩니다. 내역은 **변경 기록**에서 확인합니다.
